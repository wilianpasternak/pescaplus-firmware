# Pesca Plus — firmwares

Repositório **somente com os firmwares compilados** do módulo Pesca Plus.
O app consulta o `firmware_latest.json` para oferecer atualizações via Bluetooth.

O código-fonte não fica aqui.

## Arquivos de cada release
- `firmware.bin`: atualização pelo app (OTA).
- `PescaPlus-<versao>-completo.bin`: imagem completa para gravar via USB no endereço `0x0`.
